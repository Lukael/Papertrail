# 논문 제목 검색과 태그 검증

- 제목 검색: 한글 부분 검색, 대소문자 무시, 양끝 공백, 빈 검색어, 일치 없음, 기존 정렬 유지 PASS.
- 태그 저장: 논문별 분리, 재로드, 공백 정리, 중복 제거, 전체 삭제, 32개·64자 제한 PASS.
- 저장 실패: 검증 실패 시 기존 파일 보존, 없는 논문 디렉터리 미생성, 심볼릭 링크 거부 PASS.
- 태그 편집창: 격리된 프로덕션 SwiftUI View에서 키보드로 추가, 입력 중인 태그 저장,
  대소문자 중복 제외 PASS. 저장 전 사본 편집·취소 및 삭제 경로는 코드 검토했다.
- Xcode release 앱 빌드와 서명, Gate0GTests 16/16 PASS.

기존 데이터베이스 스키마를 변경하지 않으며 태그는 논문 폴더의 tags.json에 저장한다.
원시 로그·임시 실행 파일은 `.build/scenarios/paper-search-tags`에 있다.
실제 사용자 논문과 태그를 수정하지 않았고 채팅은 전송하지 않았다.

현재 네이티브 테스트 환경의 접근성 트리에는 SwiftUI 버튼이 나타나지 않아 Remove/Cancel
버튼 클릭은 자동화하지 못했다. cacheDisplay 비트맵은 입력 필드만 포함하므로 전체 외관
검증의 증거로 사용하지 않았다. 이 제한을 전체 UI 통과로 해석하면 안 된다.
