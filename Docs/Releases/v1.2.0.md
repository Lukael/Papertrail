# Papertrail v1.2.0

2026-09-22 · 앱 버전 1.2.0 · 빌드 7

## 변경 사항

- PDF 본문 검색과 검색 결과 간 이동을 지원합니다.
- 검색어 입력 중 PDF를 반복해서 검색하지 않도록 지연 처리합니다.
- 채팅에서 Shift+Enter로 커서 위치에 줄바꿈을 넣고 Enter로 전송합니다.
- 다크 모드 PDF 테두리가 툴바 영역으로 넘어오는 문제를 수정했습니다.
- v1.1.2의 질문 미리보기와 클릭 영역 수정도 포함합니다.

## 설치와 호환성

Apple Silicon, macOS 14 이상용입니다. ZIP을 풀어 기존 Papertrail.app을 교체합니다.
Codex CLI 설치와 로그인이 필요합니다. 앱은 ad-hoc 서명되며 Apple 공증은 되어 있지 않습니다.
배포 파일은 `Papertrail-v1.2.0-macos-arm64.zip`과 `SHA256SUMS.txt`입니다.

## 검증

- PDF 대소문자 무시 검색, 페이지 간 결과 이동, 검색 해제, 문서 전환 회귀 검사 통과.
- 질문 탐색의 네이티브 레이아웃 6가지와 클릭 영역 검사 통과.
- 60개 메시지가 있는 채팅에서 Shift+Enter 줄바꿈, Enter 전송, 입력 초기화와 진행 상태 검사 통과.
- 배포 앱 빌드와 ZIP 압축 해제 후 버전·빌드 번호·서명 검증.
- 검증 로그는 `.build/scenarios/release-1.2.0`에 보관합니다.
- 실제 Codex 생성, 물리 트랙패드, 다크 모드 외관의 수동 검사는 이번 릴리스에서 재실행하지 않았습니다.
