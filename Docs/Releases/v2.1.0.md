# Papertrail v2.1.0

2026-10-28 · 앱 버전 2.1.0 · 빌드 9

## 변경 사항

- 리뷰 패널의 **Export PowerPoint…**로 선택한 버전을 편집 가능한 .pptx로 저장합니다. 슬라이드에는 bullet과 페이지 표시, 논문 PDF에서 잘라 낸 그림·표가 들어가고, 발표 대본·그림 설명·수식 의미·예상 질문은 발표자 노트로 들어갑니다. Google Slides와 Keynote에서도 열립니다.
- 대화가 길수록 채팅 입력이 늦어지고, 답변이 나오는 동안 앱 전체가 멈칫하던 문제를 고쳤습니다. 메시지 40개에서 키 입력 한 번의 처리 시간이 65 ms에서 11 ms로, 답변 갱신이 31 ms에서 10 ms로 줄었고 대화가 길어져도 늘지 않습니다.
- 서식과 수식 변환을 메인 스레드 밖에서 처리해 긴 대화를 여는 시간이 줄었습니다. 수식 메시지 20개 기준 1.1초에서 0.4초입니다.
- 앱을 다시 켜거나 논문을 열면 채팅이 가장 최근 메시지에서 시작합니다. 맨 아래에 있으면 새 답변을 따라 내려가고, 위로 올려 읽는 중에는 끌어내리지 않습니다.
- PDF를 스크롤·확대할 때마다 저장하고 논문 목록을 다시 읽던 동작을, 멈춘 뒤 0.5초에 한 번 저장하도록 바꿨습니다.
- 다른 논문을 열면 진행 중인 문서 생성이 중단된 것으로 표시되던 문제를 고쳤습니다. 중단된 생성은 앱 시작 때 한 번만 정리합니다.
- 시간 초과된 답변도 **Retry**할 수 있고, 같은 질문을 다시 보낸 뒤에는 이전 Retry가 사라집니다. 질문이 저장되기 전에 전송이 실패하면 입력한 내용이 입력창에 돌아옵니다.
- 리뷰 본문에 `target = r`, `one = 1`, `data:image/`, `@import` 같은 글이 있으면 단어가 지워지거나 문서가 금지 구문으로 거부되던 문제를 고쳤습니다. 이 검사는 이제 태그와 스타일 블록에만 적용됩니다.
- 메모·태그 파일을 읽을 수 없을 때 다음 저장이 그 파일을 덮어쓰지 않습니다.
- 하단 로그 기록 창이 항목 500개 이후에도 새 항목을 따라갑니다. PDF를 가져올 때 제목을 한 번만 읽고, 쓰지 않는 코드를 정리했습니다.

## 설치와 호환성

Apple Silicon, macOS 14 이상용입니다. ZIP을 풀어 기존 Papertrail.app을 교체합니다.
Claude Code CLI 설치와 로그인(`claude auth login`)이 필요합니다. 앱은 ad-hoc 서명되며 Apple 공증은 되어 있지 않습니다.
저장 형식은 바뀌지 않아 2.0.0 라이브러리를 그대로 엽니다.
PDF를 스크롤한 뒤 0.5초 안에 앱을 종료하면 마지막 위치가 저장되지 않을 수 있습니다.
배포 파일은 `Papertrail-v2.1.0-macos-arm64.zip`과 `SHA256SUMS.txt`입니다.

## 검증

- Gate0A 17, Gate0D 19, Gate0E 31, Gate0F 22(PowerPoint 내보내기 포함), Gate0H 9, ChatMath 25 검사 통과.
- Gate0C와 Gate0G는 2.0.0 이전부터 맞지 않던 소스 문자열 검사에서 멈춥니다. 그 문자열만 뺀 사본에서 나머지 Gate0C 14개 그룹과 Gate0G 16개(리뷰 본문 보존 검사 포함)를 통과했습니다.
- 채팅 스크롤 검사 통과: 트랙패드 제스처 1,000회, 입력창, 질문 레일, 기록이 늦게 도착해도 최근 메시지에서 시작하기, 끝에 있을 때만 스트리밍 답변 따라가기.
- PDF 검색·확대·근거·하이라이트, 메모 저장소(읽을 수 없는 파일 보호 포함), 태그 저장소와 편집창, 정렬, 모델 목록 검사 통과.
- 격리된 라이브러리에서 배포 앱으로 PDF 가져오기, PDF 위치 저장과 재실행 후 복원, 실제 Claude 채팅 전송과 답변, 리뷰 패널, 답변 메모 저장, 재실행 후 최근 메시지에서 채팅이 시작하는지 확인했습니다.
- 배포 앱 빌드와 ZIP 압축 해제 후 버전·빌드 번호·서명 검증, 압축 해제한 앱 실행 확인.
- PowerPoint 내보내기를 앱에서 실제 리뷰로 실행하는 것, 물리 트랙패드, 실제 Claude 문서 생성은 이번 릴리즈에서 검사하지 않았습니다.
- 검증 로그는 `.build/scenarios/release-2.1.0`에 보관합니다.
