# Papertrail v2.0.0

2026-10-16 · 앱 버전 2.0.0 · 빌드 8

## 변경 사항

- 논문 채팅과 문서 생성이 Codex 대신 Claude Code로 실행됩니다. 이전 Codex 채팅 기록은 첫 실행 때 한 번 정리됩니다.
- 툴바의 모델 메뉴 하나에서 Claude Opus·Sonnet·Haiku 계열과 effort를 고르며, 채팅과 문서 생성에 함께 적용됩니다.
- 리뷰 문서가 15장 안팎의 저널클럽 발표 자료로 바뀌었습니다. 슬라이드마다 핵심 bullet이 보이고, 발표 대본·그림·표 설명·수식 해설·예상 질문은 접혀 있습니다.
- 방법 슬라이드에 핵심 수식 카드(수식, 의미, 변수표)가 붙습니다.
- 생성 중 하단 로그에 작성 중인 슬라이드와 경과 시간이 표시됩니다.
- 근거 발췌가 원문과 맞지 않으면 해당 항목만 다시 받아 교정합니다. 그래도 맞지 않는 근거는 그 근거에만 기대던 항목과 함께 빼고 문서 상단에 검증 경고로 표시합니다. PDF의 줄 끝 하이픈과 합자는 불일치로 보지 않습니다.
- 채팅 답변의 `[p. N]` 인용과 리뷰의 근거 페이지(p.N)를 누르면 PDF가 해당 위치로 이동합니다. 리뷰 근거를 PDF에 하이라이트할 수 있습니다.
- PDF에서 텍스트를 선택해 우클릭하면 설명·번역·질문을 채팅으로 보내거나 하이라이트와 메모를 남깁니다. 채팅 답변도 메모로 저장하며, 상단 **Notes**에서 모아 보고 위치로 이동합니다.
- Versions 메뉴가 버전 번호와 생성 시각으로 구분되고 선택된 버전에 체크 표시가 붙습니다.
- Ctrl+스크롤로 PDF를 확대·축소하고, 응답을 기다리는 동안에도 다음 질문을 입력할 수 있습니다.

## 설치와 호환성

Apple Silicon, macOS 14 이상용입니다. ZIP을 풀어 기존 Papertrail.app을 교체합니다.
Claude Code CLI 설치와 로그인(`claude auth login`)이 필요합니다. 앱은 ad-hoc 서명되며 Apple 공증은 되어 있지 않습니다.
이전 버전에서 만든 리뷰는 저장된 형식 그대로 Versions 메뉴에서 열리며, 새로 생성하는 문서부터 발표 형식이 적용됩니다.
배포 파일은 `Papertrail-v2.0.0-macos-arm64.zip`과 `SHA256SUMS.txt`입니다.

## 검증

- Gate0A 17, Gate0D 19, Gate0E 31, Gate0F 21, Gate0H 9, ChatMath 25 검사 통과.
- PDF 검색·확대, 근거 위치 찾기(줄 끝 하이픈·합자 포함), 선택 메뉴, 하이라이트 그리기·위치 판정·삭제 검사 통과.
- 메모 저장소의 저장·다시 읽기, 크기 제한, 심볼릭 링크 거부 검사 통과.
- 실제 Claude로 11쪽 논문의 발표 자료 생성 통과(슬라이드 18장, 근거 82개, 수식 카드 4개, 교정 없음).
- 앱에서 채팅 인용 이동, 리뷰 근거 이동, 하이라이트·메모 추가·편집·삭제·이동, 채팅 답변 메모 저장을 확인했습니다.
- 배포 앱 빌드와 ZIP 압축 해제 후 버전·빌드 번호·서명 검증.
- Gate0C 작업 공간 소스 검사와 Gate0G 질문 레일 소스 검사는 이전 버전부터 실패하며 이번 릴리즈에서도 그대로입니다.
- 실제 Claude 교정·근거 자동 제거 실행, 여러 페이지에 걸친 하이라이트, 물리 트랙패드는 검사하지 않았습니다.
- 검증 로그는 `.build/scenarios/release-2.0.0`에 보관합니다.
