# Papertrail v1.1.2

2026-09-15 · 앱 버전 1.1.2 · 빌드 6

채팅 질문 탐색의 미리보기와 버튼 클릭 영역을 수정했습니다.

## 수정 사항

- 질문 미리보기를 질문 목록의 스크롤 영역 밖에 표시해 잘리는 문제를 수정했습니다. 질문 번호와 내용을 최대 두 줄로 표시합니다.
- 질문 표시의 클릭 영역을 36×24pt로 넓히고, 작은 표시 옆의 빈 여백도 클릭할 수 있게 했습니다.
- 이전·다음 질문 버튼의 클릭 영역을 36×32pt로 넓혔습니다.
- 탐색 UI의 전체 너비 46pt와 목록 높이 최대 320pt를 유지합니다.

## 설치와 호환성

Apple Silicon, macOS 14 이상용입니다. ZIP을 풀어 기존 Papertrail.app을 교체합니다.
Codex CLI 설치와 로그인이 필요합니다. 앱은 ad-hoc 서명되었으며 Apple 공증은 되어 있지 않습니다.
기존 논문·대화·생성 문서 저장 형식은 변경하지 않습니다.
배포 파일: `Papertrail-v1.1.2-macos-arm64.zip`, `SHA256SUMS.txt`.

## 검증

- 질문 1·30·200개와 두 가지 창 너비를 조합한 6개 네이티브 레이아웃 검사 통과.
- 질문 표시의 빈 여백 클릭 회귀 검사 및 실제 앱의 질문 이동 확인.
- 호버 미리보기는 사용자가 실제 앱에서 정상 동작을 확인했습니다.
- v1.1.2 앱 빌드, 버전 1.1.2·빌드 6, ZIP 압축 해제 및 앱 서명 검증.
- 로컬 검증 로그는 `.build/scenarios/release-1.1.2`에 보관합니다.
- 이번 UI 수정 검증에서는 실제 Codex 응답 생성과 물리 트랙패드 시나리오를 다시 실행하지 않았습니다.
