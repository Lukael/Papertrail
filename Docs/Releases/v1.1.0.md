# Papertrail v1.1.0

2026-09-15 · 앱 버전 1.1.0 · 빌드 4

v1.0.2 이후 논문 탐색, 긴 대화 표시, Markdown 및 PDF 읽기 화면을 개선한 기능 릴리즈입니다.

## 변경 사항

- 논문 목록을 이름순·최근 업로드순·최근 사용자 채팅순으로 정렬하고 선택을 저장합니다.
- 논문 제목 검색과 논문별 태그 추가·삭제를 지원합니다. 태그는 논문당 최대 32개이며 제목 검색에는 포함되지 않습니다.
- 긴 대화는 최근 40개부터 표시하고 이전 메시지 불러오기와 과거 질문 이동을 지원합니다. 논문별 백그라운드 조회와 캐시로 전환 시 작업량을 줄였습니다.
- 질문 탐색 버튼이 큰 원으로 확대되어 채팅을 가리는 문제를 수정했습니다.
- 채팅 Markdown 제목, 강조·취소선, 목록, 인용, 구분선, 링크, 코드와 표를 표시합니다. 기존 KaTeX 수식 표시와 메시지 원문 복사를 유지합니다.
- PDF 도구 모음에 Dark PDF 전환 버튼을 추가했습니다. 완전한 검정 배경으로 반전하고 페이지 크기에 맞는 얇은 흰색 테두리를 표시합니다. 페이지 그림자는 제거했습니다.
- 다크 모드 선택을 저장하며 원본 PDF는 변경하지 않습니다. 이미지 색상도 함께 반전됩니다. 이미지 색상 보존은 이번 릴리즈에 포함하지 않습니다.

## 설치와 호환성

Apple Silicon, macOS 14 이상용입니다. ZIP을 풀어 기존 Papertrail.app을 교체합니다.
Codex CLI 설치와 로그인이 필요합니다. 앱은 ad-hoc 서명되었으며 Apple 공증은 되어 있지 않습니다.
기존 논문·채팅·생성 문서를 유지하며 태그는 논문 폴더의 별도 JSON에 저장합니다.
배포 파일은 `Papertrail-v1.1.0-macos-arm64.zip`과 `SHA256SUMS.txt`입니다.

## 검증

- Gate A/C/D/E/F/G/H와 ChatMathTests: 총 146개 그룹 통과. 이전 전체 메시지 렌더링을 전제로 한 Gate E 소스 계약 검사를 현재 표시 범위 방식에 맞췄습니다.
- 제목 검색·정렬, 태그 저장·삭제·정규화·논문 격리 검사 통과.
- SwiftData 백그라운드 채팅 조회: 다른 논문 메시지 2,000개 사이에서 대상 논문 격리·동일 시각 정렬·빈 기록 검사 통과.
- 합성 트랙패드 및 실제 채팅 View 회귀 검사 통과. 400개 메시지 비교에서 초기 수식 웹뷰 200→20개, 이번 실행의 초기 레이아웃 약 2.51초→0.57초. 환경에 따른 측정값이며 보편적인 속도 보장은 아닙니다.
- PDF 다크·라이트 전환, 순수 검정 배경, 그림자 제거, 페이지 테두리와 스크롤 정렬을 실제 앱에서 확인했습니다.
- 실제 WebKit 검사 포함 ChatMathTests 26/26 통과: 수식·표·코드 가로 스크롤과 메시지 내부 세로 스크롤 차단 확인.
- v1.1.0 배포 앱 빌드, 번들 버전 1.1.0 / 빌드 4, 서명, ZIP 압축 해제 및 압축 해제된 앱 서명 검증 통과.
- 실제 Codex 응답 생성은 이번 배포 검사에서 다시 호출하지 않았습니다. 기존 수동 생성 시나리오 기록과 이번 결정적 회귀 검사를 참고합니다.
- 로컬 원시 로그: `.build/scenarios/release-1.1.0`. 합성 입력 검사는 물리 트랙패드 전체 경로와 실제 사용자 환경 검증을 대신하지 않습니다.
