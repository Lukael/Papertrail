# Papertrail v1.1.1

2026-09-15 · 앱 버전 1.1.1 · 빌드 5

큰 화면에서 채팅의 너비와 글씨 크기를 조절하고, 긴 설명을 더 편하게 읽도록 개선했습니다.

## 변경 사항

- 채팅 본문·사용자 말풍선·입력창의 고정 최대 너비를 제거했습니다. 창이나 분할 패널을 넓히면 내용도 함께 넓어집니다.
- 채팅 상단에 **A− / 비율 / A+**를 추가했습니다. 80~200% 범위에서 10%씩 조절하며, 비율을 누르면 100%로 초기화합니다.
- 글씨 크기는 논문 전환과 앱 재실행 후에도 유지됩니다. 본문·Markdown·수식·표·코드에 함께 적용하며 날짜·도구 모음·입력창 글꼴은 기존 크기를 유지합니다.
- 본문 줄 높이 1.6배, 제목 1.3배, 코드 블록·표 1.4배, Markdown 문단 여백 0.8배를 적용했습니다. 글씨 크기에 따라 간격도 늘어납니다.
- 크기 변경 시 기존 WebView의 글꼴과 높이만 갱신해 문서 재로딩을 피합니다.

## 설치와 호환성

Apple Silicon, macOS 14 이상용입니다. ZIP을 풀어 기존 Papertrail.app을 교체합니다.
Codex CLI 설치와 로그인이 필요합니다. 앱은 ad-hoc 서명되었으며 Apple 공증은 되어 있지 않습니다.
기존 논문·대화·생성 문서 저장 형식은 변경하지 않습니다.
배포 파일: `Papertrail-v1.1.1-macos-arm64.zip`, `SHA256SUMS.txt`.

## 검증

- 실제 앱에서 좁은/넓은 채팅 패널의 가변 너비, 150% 확대, 100% 초기화, 80%·200% 버튼 제한과 재실행 후 설정 복원을 확인했습니다.
- 실제 채팅 화면에서 본문·제목·수식의 확대 및 줄 간격을 확인했습니다.
- 배포 직전 ChatMathTests와 실제 WebKit 검사 26/26 통과. 수식·표·코드의 가로 스크롤과 콘텐츠 높이를 확인했습니다.
- 합성 트랙패드 라우팅, 일반·수식·표·Markdown 채팅, 최근 메시지 범위와 긴 기록 비교 검사 통과. 질문 탐색 UI는 6개 네이티브 레이아웃에서 확인했습니다.
- v1.1.1 앱 빌드, 버전 1.1.1·빌드 5, ZIP 압축 해제 및 앱 서명 검증 통과.
- 로컬 검증 로그는 `.build/scenarios/release-1.1.1`에 보관합니다.
- 이번 변경 검증에서 실제 Codex 응답 생성은 다시 호출하지 않았습니다. 합성 입력 기반 스크롤 검사는 물리 트랙패드와 모든 사용자 환경을 대신하지 않습니다.
